[官网](https://betweenus.onecat.dev) · [下载状态](https://betweenus.onecat.dev/download/) · [隐私政策](https://betweenus.onecat.dev/privacy/) · [使用条款](https://betweenus.onecat.dev/terms/) · [购买与退款](https://betweenus.onecat.dev/purchases/) · [支持](https://betweenus.onecat.dev/support/)

“耳语”（正式英文名 `Between us`）是一款原生 iOS 双人关系应用。它不把关系表达做成消息列表，也不依赖任务、金币、角色或连续签到；两个人共同养着一个星星瓶、一只胶囊瓶和一个纸团篓，里面的星星、胶囊和纸团会随着双方留下的心意慢慢变多。

应用使用 CloudKit 双人共享、离线同步与交换打开机制。用户通过写、折、封、揉、按住、滑动和放入等连续动作完成表达。
