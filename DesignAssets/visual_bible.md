# Dear Us 视觉母版 · 首个正式视觉版本

状态：锁定中。先过母版场景和三种容器形态，再按 `asset_manifest` 逐条生成。
验收宽度：iPhone `390pt`。导出 `@2x` / `@3x` / 深色模式不算设计条目。

本文是生成脚本的造型合同，不是产品宣言。所有 `gpt-image-2` 提示词必须服从这里的材料、相机、负形和禁止项。

---

## 1. 预算

首个正式视觉版本按 **180 个设计资产条目** 锁定，合理区间 150–220。不要把每个中间帧做成完整 PNG。

| 组 | 条目 | 作用 |
|---|---:|---|
| environment | 14 | 房间、光影、各容器场景底板 |
| containers | 30 | 三种容器的主体 / 盖口 / 内腔 / 前遮挡 / 阴影 / 高光 / 开合静帧 |
| contents | 36 | 星星、胶囊、纸团 |
| logos | 30 | 应用、容器、动作、状态标志家族 |
| motion | 54 | 打开 / 放入 / Reveal，各容器 18 个关键姿态 |
| feedback | 16 | 引导、空状态、错误、录音、同步 |
| **合计** | **180** | 运行时设计条目 |

另有 3 张锁定用形态静帧（`lock_*_form`），只用于审批几何，不计入 180。

---

## 2. 资产架构

中间状态要设计，但只为「图片无法靠 transform 还原」的变化提供 4–6 张关键帧：

- 轮廓变化
- 遮挡关系
- 折叠 / 开盖
- 纸团摊平
- 胶囊裂口

普通位移、旋转、缩放、透明度、颜色和轻微弹性由 SwiftUI / Core Animation 计算。

每个容器大约：

- 10 个静态状态资产
- 18 个交互关键帧

不要生成 30 或 60 张逐帧图片。不要用两张照片叠合冒充开合。

Logo 不是换颜色。每个标志提供 16pt / 24pt / 48pt，应用标志另提供 App 图标；这些是导出尺寸，不是新条目。

---

## 3. 母版场景

安静的二人共用小房间，不是工具界面，不是奢侈品广告，不是 CG 产品渲染。

- 墙：奶油灰泥 `#F6F2E9`，占画面上半。
- 桌：比墙更深的暖橡木，占画面下三分之一。
- 光：左上窗光作主光，画面外一盏暖钨丝灯作辅光。阴影短而软。
- 相机：锁定 50mm 等效，俯视约 12–15°，焦点在桌面物件簇。物件只占画面中部约 50% 高度，上方留墙。
- 杯子 / 盒子 / 篓都是桌上小物件，禁止撑满屏。

首页布局对应关系：

1. 星星瓶稍大，靠中后。
2. 胶囊盒在前左，更小。
3. 纸团篓在前右，更小。

禁止出现人、手（关键帧另有规定除外）、手机、UI、文字、水印、logo、货架横条、办公室垃圾桶、大理石厨房。

## 4. 三种容器形态状态表

三种容器共用：同一相机、同一光、同一比例尺、同一桌面高度。合上时盖必须挡住开口；打开后开口高度不变，塞子 / 盒盖 / 篓口结构跟着打开件走，不能消失。

### 4.1 星星瓶 `star`

语义：收藏。材料：透明玻璃 + 软木/薄木盖。玻璃要看得见厚度和墙的折射，但不能是海玻璃污泥、乳白塑料或细白线框。

| 状态 | 资产 | 必须看见 | 禁止 |
|---|---|---|---|
| 主体 | `container_star_body` | 瓶身、颈、口沿；无盖 | 缩短颈口 |
| 盖 | `container_star_lid` | 盖面、盖沿、伸进瓶口的塞子 | 孤立砂锅盖、比例错配 |
| 口 | `container_star_mouth` | 完整颈口，口沿厚度 | 打开后颈变短 |
| 内腔 | `container_star_cavity` | 内部容积，可放星星 | 实心玻璃块 |
| 前遮挡 | `container_star_occlusion_front` | 前壁玻璃，用来盖住内容 | 不透明白塑料 |
| 阴影 | `container_star_shadow` | 接触阴影，透明底 | 把桌子画进去 |
| 高光 | `container_star_highlight` | 窗光造成的细高光 | 一条假的白色长条贴图 |
| 合上 | `container_star_closed` / `lock_star_form` | 盖沿完全挡住瓶口 | 透过盖看见一圈杯边 |
| 打开静帧 | `container_star_open` | 盖在一侧，微倾；塞子在盖上；颈口完整 | 盖子直线上提、颈口缩短 |
| 空 | `container_star_empty` | 打开或合上均可，腔内无星 | 假高光填满杯子 |

开盖关键帧只画人手揭盖的弧线：先离口，再沿肘腕弧到一侧，盖身绕钮倾斜。不要直线上提。

### 4.2 胶囊盒 `capsule`

语义：封存、传递。材料：鼠尾草绿珐琅小盒，圆角，细黄铜铰链。旅行药盒尺度，不是药柜。

| 状态 | 资产 | 必须看见 | 禁止 |
|---|---|---|---|
| 主体 | `container_capsule_body` | 盒底、内槽、铰链侧 | 打开后铰链消失 |
| 盖 | `container_capsule_lid` | 盒盖内面与外面 | 盖和盒不是同一几何 |
| 口 | `container_capsule_mouth` | 开口上沿 | 盖合上后仍看见内槽沿 |
| 内腔 | `container_capsule_cavity` | 分槽或浅槽，可躺胶囊 | 深到看不见底 |
| 前遮挡 | `container_capsule_occlusion_front` | 盒前壁 | 透明塑料药盒网红风 |
| 阴影 / 高光 | `container_capsule_shadow` / `_highlight` | 珐琅高光克制 | 镀铬、霓虹 |
| 合上 | `container_capsule_closed` / `lock_capsule_form` | 闭合缝一条，盖沿压住盒口 | 盖歪、缝很大 |
| 打开静帧 | `container_capsule_open` | 盖向后翻起约 70–90° | 盖飞到天上 |
| 空 | `container_capsule_empty` | 空槽 | 堆满无关药丸 |

### 4.3 纸团篓 `paper`

语义：安全承接，不是丢弃。材料：暖灰陶瓷或细藤桌面篓，书桌尺度。

| 状态 | 资产 | 必须看见 | 禁止 |
|---|---|---|---|
| 主体 | `container_paper_body` | 篓壁、底 | 办公室垃圾桶、金属脚踏桶 |
| 口 | `container_paper_mouth` | 承接口沿，略外翻 | 锋利工业边缘 |
| 内腔 | `container_paper_cavity` | 浅腔，能看见底 | 深不见底的洞 |
| 前遮挡 | `container_paper_occlusion_front` | 前壁，纸团可被挡住 | 完全透视线框 |
| 阴影 / 高光 | `container_paper_shadow` / `_highlight` | 陶/藤的哑光 | 塑料桶高光 |
| 合上 | `container_paper_closed` / `lock_paper_form` | 篓口完整，纸团在腔内 | 纸团漂在篓外 |
| 打开静帧 | `container_paper_open` | 同一篓，口沿无遮挡，准备承接 | 变成另一个容器 |
| 空 | `container_paper_empty` | 空腔 | 垃圾袋、回收标志 |

纸篓没有独立硬盖。所谓「打开」是口沿承接态：前壁遮挡减少、内腔可读。

## 5. 内容物

- 星星：手工折纸，暖琥珀 `#E69E42`，边不完美。不是五角金属徽章。
- 胶囊：两截，鼠尾绿 + 奶油，磨砂，不是透明药。
- 纸团：暖灰手写纸揉成团，能看出纸层，不是白球。

---

## 6. Logo 形态家族

同一负形、线宽、几何比例。24 网格，线宽 1.75，圆端圆角。16pt 只保留剪影；24pt 加一个内形；48pt 完整；App 图标把应用标志放在暖纸底上，无玻璃高光。

| 标志 | 语义 | 负形 |
|---|---|---|
| `logo_app` | 两个人共同保存 | 两个容器轮廓重叠，共享一个内腔 |
| `logo_star` | 收藏 | 瓶口负形里一颗星 |
| `logo_capsule` | 封存传递 | 胶囊被一条封口线分成两半 |
| `logo_paper` | 安全承接 | 两道弧合成篓口，接住一小折纸 |
| 动作 | 折 / 封 / 揉 / 打开 / 放入 / 回应 | 同一线宽的手势符号，不是 SF Symbol 放大 |
| 状态 | 待打开 / 看过 / 草稿 / 同步 / 离线 / 错误 / 空 / 录音 | 同一家族的小标记，不靠换色区分 |

禁止：只改颜色假装成另一标志；16pt 塞细节；渐变描边；拟物 App 图标反光。

## 7. 动效关键帧规则

每类交互 6 帧，只保留轮廓/遮挡/折叠变化。

- `f01` 起点静帧
- `f02` 关系刚被破坏（盖离口、纸一角松开、胶囊出现封口裂缝）
- `f03` 中间不可插值姿态
- `f04` 接近完成的遮挡变化
- `f05` 打开后的静止姿态
- `f06` Reduce Motion 可直接跳到的静态替代，或完全摊平/完全裂开的终态

位移和透明度不单独出图。

---

## 8. 命名、锚点、通道

命名：`{object}_{name}_{state}_f{frame}`，例如 `container_star_open_f03`、`logo_capsule_active`。

| 字段 | 约定 |
|---|---|
| canvas | 房间 `1024x1536`；物件/标志/关键帧 `1024x1024` |
| 透明 | 环境底板不透明；物件层、内容、标志、关键帧透明 |
| 锚点 | 桌面物件底部中心约 `(0.50, 0.82)`；标志中心 `(0.50, 0.50)` |
| 明暗 | 物件本身不复制深色套；深色房间用 `env_room_night` 底板 |
| Reduce Motion | 指向对应序列的静止帧，不新造条目 |

## 9. 生成纪律

1. 先生成并人工锁定 `env_room_master`。
2. 再从母版 edit 出三张容器形态静帧。
3. 其余条目必须引用已锁定图像，禁止模型自由发挥 100 张互不相干的 PNG。
4. 在 390pt 宽 iPhone 上看：轮廓、遮挡、边缘脏边、比例。
5. 未过母版之前，不要跑 `--stage production`。
